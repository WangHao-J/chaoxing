# 学习工作台 1.7.7 · 全量升级

多账号统一工作台、账号分类与共享 API 设置；登录后读取课程，提供运行记录、待处理和分账号报告。失败章节继续后续任务，首轮结束后最多重跑三轮，最后列出未完成项。

全量包包含 Windows x64 Python 运行环境。先退出原程序，选择原安装目录；安装器先备份，再覆盖程序，保留原账号和设置。需要回退时再次运行安装器并选择恢复程序。

本包用于已有本项目桌面版目录的升级，目录应包含 account_manager.py 和 app/main.py。新用户请按 README 从源码运行。

安装器与对应 SHA-256 文件由同一提交构建。发布前应检查 Actions 成绩和隔离升级冒烟测试。草稿不代表已向用户发布，也不代表真实课程均可完成。

源码、GPL-3.0 和第三方说明见本版本对应提交的 README 与 docs/。安装包不含维护者账号、Cookie 或 API 密钥。
