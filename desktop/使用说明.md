# 学习通助手 1.7.7：单窗口工作台

打开原来的快捷方式或 `start.cmd` 即可进入新工作台。

- 左侧搜索、筛选和切换账号；右侧始终显示当前操作账号。
- 登录成功后自动加载课程；打开已有登录记录的账号时也会自动加载。选择运行方式、勾选课程后即可开始。
- 课程页不再显示“读取课程”按钮。加载失败时，检查登录或网络状态后，可点击“重新打开此账号”重试。
- 切换账号或查看设置不会停止其他账号。停止按钮只作用于当前账号。
- 需要答题或处理异常时，左侧账号显示“等待处理”，点击它的“任务详情”即可在同一窗口操作。任务提示不会抢走正在使用的页面。
- “待处理”汇总当前账号的各模式记录。打开所选任务前，需要先停止本账号正在运行的任务。
- “账号登录”在当前页面完成登录，成功后自动回到课程页并加载课程。
- 右上方“收起到任务栏”保留后台任务；关闭主窗口会安全停止工作台中的账号，并等待正在提交的操作返回。
- 再次打开快捷方式会显示已经打开的工作台。
- 左侧账号按分类展开显示。点击“新建分类”创建分类，选中账号后通过“整理账号”或右键菜单移入分类；分类也可重命名和删除。删除分类会把其中账号移入“未分类”。分类信息保存在安装目录的 `account_groups.json`，不移动账号资料。
- 底部提示条右侧可以点击“关闭”收起当前提示；有新提示时会重新显示。
- 展开运行记录后显示更大的阅读区域和滚动条。向上翻阅记录时，新消息不会强制把阅读位置拉回末尾。

## 统一 API 设置

API 设置入口仅保留在右上方。“统一 API 设置”对全部已有账号和新账号生效，保存一次即可。API Key 继续使用当前 Windows 用户的加密服务保存。

如果旧账号中只有一套有效配置，会自动迁移。如果检测到不同配置，首次进入设置页后，从“导入原有配置”选择一个账号，点击“载入”，核对后“保存设置”。以后新增账号无需重复填写。

原账号配置文件保留用于回退。正在处理的测验可能仍使用开始时的配置，新配置用于后续测验。

## 时长估算与章节顺序

预计用时优先读取完整的待处理音视频，按账号实际播放进度扣减，并随播放进度更新。只缓存媒体总时长，各账号播放进度独立读取。未能完整读取时显示已知用时下限和读取覆盖范围，不把少量样本直接倍乘为整门课程的确定时间。答题、人工验证、网络等待不计入音视频用时。

当前章节结束后先复查平台状态。仍未确认或本章读取、处理失败时，保留该章并继续后续可执行章节，不连锁阻塞整门课程。独立视频或独立答题模式以当前模式内任务的明确完成标记为准，其余类型继续保留为待处理。程序不会因任务从页面消失而猜测它已经完成。

## 分账号运行报告

账号详情的“运行报告”汇总等待平台确认、网络失败、人工处理、未开放以及前置章节阻塞等情况。每轮结束、停止或处理所选测验后自动保存；也可点击“汇总当前记录”生成本地记录快照。

报告独立保存在安装目录的 `reports/账号编号/`，包含 `latest.md`、`latest.json` 和 `history/` 历史记录。在界面点击“打开本账号报告目录”即可找到。历史快照会明确标记尚未在线核对；失败和未执行不会被自动判定为永久无法完成。

## 版本基础

1.7.7 在本机 1.7.6 的基础上增加账号分类、完整度明确的音视频时长估算、章节确认顺序控制和分账号报告。题型适配和答案提交仍沿用原有逻辑。

已完成原有回归、离线多账号运行、账号切换、公共配置继承、双后台答题和提交中安全退出检查。没有用真实课程交卷作为测试；课程完成情况仍以平台确认结果为准。

升级前的程序保存在安装目录 `backups/before-groups-reports-20261027-143648`。需要回退时，先退出工作台，再将该目录的同名程序文件（含 app 子目录）覆盖回安装目录；账号资料无需恢复或删除。




## 2026-10-28 更新：章节跳过与最多三轮自动重跑

- 章节读不到任务、处理失败或结果未确认时，保留原因并继续下一章。
- 每轮检查完全部所选课程后，若仍有未完成项，自动重新读取所选课程目录并继续。
- 首轮 + 最多重跑三轮，共最多四轮。提前清空本模式待处理队列即结束。
- 重新读取时跳过平台明确确认完成的章节；提交结果不确定的测验仍不会自动重复提交。
- 单门课程目录读取失败也会记录并继续其他课程，下一轮再次核对。
- 真正的登录失效、验证码、限流和用户停止仍走明确暂停或停止流程，不强行自动继续。
- 界面显示每轮已检查数，成功数单独汇总。运行报告列出剩余课程、章节、原因与轮次信息。
- 轮次在一次点击“开始”期间计算；手动重新开始会开启新的首轮。

本更新基于已安装的桌面 1.7.7，保留统一 API、账号分类和开始前自动答题开关。
这是本机更新包，不更新服务器。未使用真实课程或交卷验证本次调度变更。
