# 桌面版架构

入口：`desktop/account_manager.py` 的普通启动转交 `workspace.entry`。一个可见工作台通过嵌入页面展示课程、登录、待处理与报告。

`WorkerClient` 为账号创建隐藏 Python 后台，通过逐行 JSON 管道传递请求、结果、状态事件和界面回调。上游包含进程内共享会话与相对文件路径；独立进程配合独立工作目录减少账号串号风险。

`StudyEngine` 负责读取目录、模式筛选、任务执行和确认。失败项保留原因并继续其他章节；每轮重新读取所选课程，首轮后最多重跑三轮。真实登录失效、验证码、限流及用户停止仍进入明确暂停或停止流程。

安全读取和视频恢复有界重试，视频恢复前重新匹配同一任务并读取平台进度。提交账本先写 `uncertain` 再发请求，收到明确成功后改为 `acknowledged`，未知结果不直接再次交卷。

媒体总时长可按对象缓存，账号播放位置独立读取。报告分账号保存 JSON、Markdown 和历史快照，区分本地记录与在线核对证据。

账号目录、Cookie、密钥、报告和安装器备份属于运行数据，不作为源码发布。`full_upgrade.py` 只替换清单列出的程序文件，覆盖前备份并核对原文件，保留原 `app/config.ini`。
